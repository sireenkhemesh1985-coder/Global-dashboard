## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- Git

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/sireenkhemesh1985-coder/Global-dashboard.git
   cd Global-dashboard
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch the Streamlit command platform:
   ```bash
   python -m streamlit run dashboard.py
   ```

4. Open your browser at:
   ```
   http://localhost:8501
   ```

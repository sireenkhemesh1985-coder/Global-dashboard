# ZEUS Global Market Intelligence (ZGMI) ⚡

**Global Distributor Management & Strategic Decision Support Platform**

ZGMI is an executive-grade commercial intelligence and decision-support web application tailored for medical biotechnology and Assisted Reproductive Technology (ART) / IVF laboratory innovations.

---

## 🌟 Key Features

- **◈ Executive Command Center:** 6 core financial KPIs, multi-layer analytics, and global territorial tracking.
- **🌐 360° Rotating 3D Earth Globe:** Interactive, rotatable spherical globe with vibrant 6-region color coding (Europe, MENA, APAC, LATAM, Africa, North America).
- **✦ AI Intelligence & Predictive Analytics:**
  - *Declining Product & Risk Detection:* Automated anomaly detection identifying drops in equipment/consumable orders.
  - *Next Month & Quarter Sales Forecasting:* Machine-learning polynomial regression with 95% confidence corridors and seasonal indices.
  - *Regional Weaknesses & White-Space Gap Analysis:* Maps IVF clinical capacity against current penetration to uncover multi-million dollar growth opportunities.
  - *AI Executive Copilot:* Generates structured strategic action plans and executive memos.
- **◇ International Distributors & CRM:** Complete partner directory with LOA compliance health, exclusivity tracking, and candidate registration.
- **▤ Agreements & Compliance:** Contract validity, Letter of Authorization renewals, and exclusivity governance.
- **◬ Sales & Product Analytics:** Product breakdown across the 5 ZEUS lines (*Pulse Stimulator, BioPSafe Black-Box, Mismatch Blocker, Smart Cryo-Tools, Electro-Fusion*).
- **◎ Global Market Intelligence:** Comprehensive clinical benchmarking across 48 countries with side-by-side comparison tools.
- **⌘ Pricing & Margin Calculator:** Volume tiers (Tier 1–3), logistics allowance, commission, gross margin deltas, and automated executive approval checks.
- **⛛ Risk & Scenario Simulator:** Financial stress-testing across FX fluctuations, demand shocks, price pressure, and payment defaults.
- **▲ Performance Evaluator:** Multi-factor weighted scorecards assessing target attainment, sales velocity, and clinic acquisition.
- **⚖ Strategic Decision Center:** Weighted multi-criteria decision engine for high-stakes commercial authorizations.
- **⇲ Executive Reports & Certified Export:** Audit briefings and one-click CSV dataset downloads.

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- Git

### Installation

1. Clone this repository:
   ```bash
   git clone <YOUR_REPO_URL>
   cd dashboard.py
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch the Streamlit platform:
   ```bash
   streamlit run dashboard.py
   ```

4. Open your browser at:
   ```
   http://localhost:8501
   ```
